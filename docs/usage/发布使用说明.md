# CodexPrefix 0.7.0-rc.1 候选版使用说明

Windows x64 免安装；完整复制本目录，退出旧工具后运行 `./CodexPrefix.exe`，不需要 API Key 或额外 .NET 环境。

本候选完成构建与隔离自检，实际 Codex 自动入口、托盘点击和焦点体验仍待人工验收。固定日常发布版在验收前保持原版本。

## 使用与收纳

- 在 Codex 中选中会话，点击工具编辑入口。正式入口通过顶部“聊天工具栏”的标题菜单选择“重命名”，随后绑定原生弹窗；不发送 Ctrl+Alt+R。无法确认唯一工具栏或原生弹窗时，请手动点击顶部标题菜单中的“重命名”。
- 弹窗就绪后点击前缀或清除，工具核对输入框及原文后调用保存按钮。显示“已提交”后仍应核对原生会话名，不把控件消失当作持久化成功。
- 工具启动时有可核验的 Codex 主窗口才显示；没有目标时只留托盘。宿主最小化时暂时隐藏，恢复后继续；宿主关闭或身份失效后收纳并暂停，重新打开 Codex 后必须从托盘“启用辅助”恢复。
- 浮窗关闭按钮收纳并暂停；真正退出使用托盘“退出”。双击托盘可启用辅助。多窗口不能确认目标时先激活目标 Codex。

## 列表与配置

- 设置列表可添加、待删/撤销、拖拽排序；勾号始终保存个人列表，叉号取消草稿。
- 底部切换按钮在个人列表和默认模板之间切换，个人列表保留。编辑态的单独模板按钮将草稿另存为“本机默认模板”，不改程序文件或源码资源。
- 配置固定在系统 LocalApplicationData 的 `./CodexPrefix/`：`emoji-settings.json` 为个人列表，`default-template.json` 为本机模板，`prefix-history.json` 为跨模板历史登记，`settings.json` 为置顶和活动模式。迁移电脑时复制完整配置目录中的这些文件；不要用默认预设覆盖个人列表，不要删除 emoji 内部的资格变体或连接符。
- 程序目录 `default-emojis.json` 是随版本分发的初始预设；它不会覆盖已保存个人列表或本机模板。文件损坏时保留原件并停止相应写入，不静默重置。

## 公开仓与本地目录自更新

默认从公开仓 `areusa/CodexPrefix-Release` 静默检查版本；点击底部更新按钮可手动检查，发现更高版本后再次点击才下载并替换。下载文件固定到相同版本 tag；tag 未完整发布时停止。正式版不会自动接收候选版。右键更新按钮可改为从另一份新版完整 `release` 文件夹离线更新。列表有草稿时先保存或取消。

更新先核对版本清单、白名单与逐文件 SHA-256，再建立可恢复事务并替换；新版在配置与消息循环初始化后提交启动健康回执，失败恢复旧文件。启动健康检查不代表真实 Codex 版本兼容性已通过。备份与事务只保存在用户配置目录的 `./updates/`，不按扩展名清理无关文件。

核心改名离线；仅更新检查和下载通过只读 HTTPS 访问公开分发仓，不上传会话、配置或认证信息，不需要个人令牌。公开仓包含已脱敏源码及必要交付件，私有开发仓保持独立。测试/`--data-dir` 隔离模式禁止原位更新、联网检查与正式托盘。

## 诊断与许可

UIA 无响应会终止本工具的隔离工作进程；写入不确定时不会自动重复保存，请先核对原生界面并关闭原输入框重开。“诊断”可能包含可见名称，分享前检查。

许可见 `./THIRD-PARTY-NOTICES.txt` 和 `./licenses/`；版本与完整性交付清单见 `./version.json`、`./SHA256SUMS.txt`。目录没有测试夹具、个人配置或压缩包。
