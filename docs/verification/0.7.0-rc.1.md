# 0.7.0-rc.1 候选版验证记录

日期：2026-11-24。

## 实现范围

- 正式入口从唯一聊天工具栏标题菜单触发重命名，再绑定原生弹窗并调用保存按钮；保留官方包、文档、控件身份和原文核验。演示时序夹具保留原测试快捷键，正式入口不使用它。
- 修复小条置顶层传播、初始面板命中、只读 UIA 瞬态恢复；保持单主 HWND、真实面板转场及 1.08 倍 hover。
- 托盘采用系统框架菜单。宿主关闭后隐藏并封锁，不因重新打开宿主自动恢复；宿主最小化时暂时隐藏，恢复后继续。
- 勾号保存个人列表；模板单独保存用户目录；独立历史登记保留旧前缀，不写回源码或程序文件。
- 更新固定到对应公开版本 tag，也支持本地完整交付目录。检查更新不阻塞改名；替换前后复核哈希，失败恢复旧文件，并等待新版启动健康握手。保留事务备份，不清理无关 .old 文件。

## 已通过

- Windows x64 自包含单文件构建，0 警告、0 错误。
- 1881 项规则/资源/配置/离屏布局自检，其中新增 76 项针对本次升级；无按键、鼠标或前台切换。
- 27 项隔离自动化工作进程故障验证，不创建真实 UIA、不连接真实会话。
- 新增验证涉及：模板与个人配置隔离、跨重启历史、损坏配置保护、原子保存失败、0/1/6/7/12/40 项离屏布局、浮层根画布归属、更新校验、替换中断恢复、健康回执代次与版本、禁止更新个人配置以及稳定/候选渠道隔离。
- 所有交付文件按白名单生成，包含完整 SHA-256 清单和第三方许可；源码 UTF-8 与脱敏检查通过后才导出。

## 未完成的实际验收

真实 Codex 菜单自动打开、改前缀并持久化、清除、托盘真实通知到菜单命令、宿主关闭/重开、前后台焦点、IME、滚动与连续屏幕首帧仍需人工验收。此前仅观察了标题菜单和弹窗并取消，不能等同于本候选的端到端验证。

更新事务测试使用假的 MZ 字节作为文件载荷，从未执行这些假程序；已验证真实文件替换和恢复，但没有进行真实旧版到新版的进程重启安装。启动健康握手只证明程序、配置及消息循环就绪，不代表宿主版本兼容性。

不将本候选称为日常稳定版，正式通道不会自动推送候选版本。未修改真实会话名称，未用测试配置覆盖用户列表。
